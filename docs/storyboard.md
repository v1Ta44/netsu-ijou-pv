## 0. 角色：足立レイ本人

叙述者即足立レイ。所有角色组件必须使用足立レイ的官方形象，不做原创变体。

- 形象细节以官方立绘为准，生图前需准备参考图（见 §3），据此写定 CHARACTER 段 prompt。
- 两套画风：所有生图组件（足立レイ、物件、背景）统一为参照图 `assets/ref/style_ref_rei.png` 的手绘向平涂（抖动细线、粗糙笔触、简单平涂、几乎无光影，角色比例不标准）；系统层 = SVG 硬边矢量。
- 角色属于"叙述者"一侧，她的动作在代码里严格跟拍（世界组件不跟拍）。
- 全片拒绝拟人与非现实的物件处理：月亮、星、物件都不长脸、不长眼。
- 色调统一在合成阶段处理（方案 B）：生图阶段不调整色调，prompt 里不写任何暗、浓、压抑、配色或氛围词，只出固有色干净的平涂组件；压黑、提对比、高饱和由 Remotion 后处理按段落热度施加。

## 4. 生图风格控制

所有生图组件统一走图生图：`--image assets/ref/style_ref_rei.png`，模型 `gpt-image-2.5-sunburst`。色调在合成阶段统一处理（方案 B）。

prompt = `REF_LOCK + 类型约束 + SUBJECT + FRAMING`。

REF_LOCK（全部组件共用）：
```
Use the reference image ONLY as a drawing-style reference. Copy its drawing style exactly: rough hand-drawn anime look,
dark wobbly uneven lines that are slightly sketchy, simple flat coloring in large flat areas with almost no shading,
slightly imperfect and unpolished like an indie animator's drawing.
No film grain, no noise, no chromatic aberration, no text.
```

类型约束：
- 角色（足立レイ）：`Also keep the same character design as the reference.` 加 `Do NOT copy the reference composition: no close-up profile holding a device`；比例 `head a little large, legs a little short, stiff awkward posture`。
- 物件 / 背景：`Do NOT copy anything else from the reference: no girl, no person, no hair, no voice recorder, no gradient sky.` 加 `Objects are drawn as real things: no faces, no eyes, no anthropomorphism, nothing cute or cartoonish.`

CHARACTER：以 [docs/character.md](character.md) 为准（公式立绘锁定）。生图用多参考图生图：画风 `assets/ref/style_ref_rei.png` + 设计 `assets/ref/rei_front.png`（+ 背影时 `assets/ref/rei_back.png`）。形象基准图：`assets/gen/char_lock_v1/REI_front.png`、`REI_back.png`。

要点：
- 透明底写 `single isolated subject, transparent background, no shadow`，配合 `--transparent`；导出后清除低于阈值的半透明残留。
- 背景写 `empty scene, no people`。
