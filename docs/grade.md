# 调色定稿（方案 B）

> 实现：`pv/src/grade.tsx`。生图只出中性固有色组件，色调全部在这里施加，由单一参数 `heat`（0–1）驱动。

| 档位 | heat | 世界层（梯度映射） | 角色层 | 系统层 UI |
|---|---|---|---|---|
| 冷 | 0 | 近黑 → 深海军蓝 → 灰蓝 | 偏冷，白衣仍最亮 | `#E8ECEF` |
| 暖 | 0.33 | 近黑 → 焦褐 → 橙 `#C2410C` → 琥珀 | 偏暖 | `#FFC94A` |
| 热 | 0.66 | 近黑 → 深红 → 朱红 → 橙红 | 偏暖红 | `#FF7A45` |
| 过热 | 1 | 暗红线稿 → 朱红 → 白热 + 径向白热光晕 | 轻微提亮 | `#FFF3E6` |

规则：
- 世界层：亮度 → 色阶压黑 → 5 段梯度映射，再按 `keep` 保留少量原色相。暗部第 2 段（0.04）让平涂比线稿亮一档，保住地面层次。
- 角色层：单独调色，白衣始终是画面最亮的元素；黑色部位（连裤袜、高领、头戴设备）整体抬升 `CHAR_LIFT = 0.1`，不与压黑的地面融合；橙色识别色保留。
- 光源（月、日、火光）：只用形状做光线剪影（`LightSilhouette`），亮度上限为角色白的 85%；过热档解除上限并半透明溶入眩光。
- 过热档：`WhiteHeat` 径向光晕（screen 混合）自 heat 0.66 起渐入，中心位置可调，正式分镜中放在角色侧后方。
- 文字与 UI：底板用当前档最暗色（`plate`），歌词固定近白。
