## 0. 视觉语言（四个签名）

1. **记录体**：全曲 126 行歌词即 126 条记录。HUD 常驻：四角对位标、REC ● + 时间码（左上）、TEMP（右上）、记录行号 `0001 / 0126`（左下）、段落码 `SEC.A / MONOLOGUE`（右下）。HUD 本身随剧情劣化，I 段碎裂，J 段只剩一行。
2. **巨型明朝**：关键字（熱・星・鐘・砂・海・夢・喉）做成超出画框的巨型字，一部分当"窗"：字形作遮罩，世界从字里透出来。
3. **剪贴的世界**：混乱段的世界组件不满幅铺，而是硬边矩形剪片——倾斜、堆叠、带硬投影、溢出画框、不清除。平静段才给满幅。
4. **单变量色彩**：整片只由 `heat` 驱动（cold→warm→hot→overheat），每个画面近似双色调 + レイ的橙 + 字白 + REC 红。冷蓝只在 H「あなた」出现一次。

网格：12 列，左右边距 96，栏距 24。叙述者层（SVG、歌词、レイ的动作）量化到 1 / ½ / ¼ 拍；世界层随机漂移、不跟拍。レイ的立绘一律不做水平翻转。
