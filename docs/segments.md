# 《熱異常》段落划分与处理原则 v1

> 分段已与用户确认。时间轴来自 `data/lyrics.json`，BPM 184.6（1 拍 0.325s，1 小节 1.30s）。
> 本文件取代 storyboard v2 的「焦点规则」。逐镜分镜在此基础上重写。

## 0. 核心对立：末世的混乱 vs 机器的秩序

不再要求每帧只有一个焦点。画面允许无序、过载、互相遮挡。

| | 世界（末世） | 叙述者（机器人） |
|---|---|---|
| 载体 | 生图组件：背景、物件、人群 | SVG：网格、LOG 行、读数、「」、REC ● |
| 形态 | 手绘平涂、堆叠、倾斜、随机散落 | 矢量、硬边、对齐、等距、正交 |
| 运动 | 无规律：抖动、坠落、漂移、不跟拍 | 严格跟拍：量化到 1、1/2、1/4 拍 |
| 文字 | 被撕碎、重复、溢出的歌词副本 | 当前歌词：对齐网格、等宽排布 |

反差的推进：全片前半段，秩序始终压得住混乱；到 I 段，秩序本身开始崩坏（网格错位、括号碎裂）。最后一个 」 是秩序唯一的回归。

## 2. 各类段落的处理原则

### 独白（A）
- 比重：秩序 80 / 混乱 20。
- 画面空，世界只出现远景和局部，SVG 克制：一列 LOG、REC ●、TEMP 36.5。
- 切镜慢：4–8 拍一次，以推拉代替硬切。
- 歌词：明朝体，逐字打出，严格对齐 LOG 栏。

### 疾走（B、E、I）
- 比重：B 混乱 60 / 秩序 40；E 70 / 30；I 85 / 15，秩序开始崩坏。
- 切镜：句内 1/2 拍，×8 重复词段 1/4 拍。
- 混乱层：组件碎片随机散布、倾斜、重叠，旧歌词副本残留不清除，屏幕信息刻意溢出。
- 秩序层：当前歌词永远落在网格上，跟拍精确；×8 段以固定规则排布（网格、透视线、同心层），规则本身就是"机器在计数"。
- E 相比 B：矛头转向她自己，混乱开始侵入角色组件本身（剪影、瞳孔）。
- I：网格错位、括号逐层碎裂，秩序失守；终点 」 由碎片重组，恢复秩序。

### 疾走内休止（B′）
- 只有约 1 小节（1.3s），是 B 前半（電撃〜なにかが来ている）和后半（大声で泣いた後〜彼らを見ている）之间的断点。
- 画面喘息：混乱层清空，只保留一个静止画面（一幅生图组件或纯黑 + 单个 SVG 符号），不切镜、不跟拍。
- 「大声で泣いた後」第一拍瞬间炸回疾走，作为 B 后半的起爆点。
- 「そう囁いた〜舟は爆ぜた」归回普通疾走处理。

### 爆发长句（C、H）
- 比重：秩序与混乱对等，但两者都放大：组件给到大画幅特写，SVG 符号也大而少。
- 切镜：每句 1 镜（约 8 拍），单镜分量重，镜内用缓慢运动和光的变化承载情感。
- 歌词：大字号，可以压在组件上。
- H 开头一帧爆发：G 积累的热度在 H 第一拍一次性释放（全屏 HOT 配色 + 冲击帧），H 整段维持高温。
- 冷蓝只出现在 H 的「あなた」。

### 吟唱（D）
- 有声无字：她在场但不说话。
- 不出歌词；用 WAVE 声波线代替文字，线条与人声能量绑定。
- 画面以角色局部（眼、喉、手）+ 安静的背景为主，混乱降到最低。
- 秩序层表现为"系统待机"：LOG 只刷新时间戳，没有内容。

### 沉默 + 强鼓点（F1）
- 默认全黑或极暗。
- 每个强鼓点打出一帧冲击：闪现一个组件或一个 SVG 符号，然后立刻回黑。
- 画面内容只由鼓点驱动，没有连续镜头。

### 警报（F2）
- TEMP 成为主角，读数随警报持续攀升。
- 画面整体随温度推进色板：COLD → WARM → HOT，但不进 OVERHEAT（留给 H 之后）。
- 警报的周期性映射为 SVG 的扫描环、闪烁警示框；世界组件在热浪中扭曲、褪色。

### 独白 · 世界升温（G）
- 构图呼应 A，但两层分离：
  - 世界层：逐句加热。背景色温、热浪扭曲、TEMP 读数、组件的燃烧痕迹每句递增一级。
  - 叙述者层：保持 A 的冷静。歌词、LOG 栏、字体、节奏与 A 完全一致，不受升温影响。
- 反差就是这段的内容：周围在燃烧，她仍然在一行一行地记录。
- 最后一拍不做预热收尾，直接硬切到 H 的爆发。

### 后奏（J）
- 余韵与熄灭：过曝退去，低机位的录音机与花在前景，远处角色剪影。
- SVG 只剩 LOG 最后一行 → `EOF`，REC ● 与光标闪 3 次后熄灭，黑场。
