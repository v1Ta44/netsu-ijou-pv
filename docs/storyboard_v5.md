> 取代 v4 的整个镜头层。保留：`segments.md` 段落划分、`grade.md` heat 调色、记录体 HUD（REC / 时间码 / CORE TEMP / LOG.0001–0126 / SEC）。

> 实现：`pv/src/v5/`（剪辑引擎 + 镜头词汇 + 填充帧 + 混乱歌词），`pv/src/fx/signal.tsx`（失真层）。

## 0. 总原则

**疾走 = 剪辑速度。** 单帧可以很满，但过载主要来自画面切换的频率：意象镜头之间不断塞进没有意义的帧，观众来不及看清，只留下残像。

### 0.1 三个档位

| 档位 | 段落 | 基准切点 | 填充帧比例 | 闪插（1–2 帧） | 歌词 |
|---|---|---|---|---|---|
| **T1 满速** | B / E / I | ½ 拍（≈5 帧）；×8 重复段 ¼ 拍 | 30% | 26%（另 16% 为高速转场） | 普通句每 1 拍换排布；×8 段每个切点换 |
| **T2 慢一档** | C / H | 1 拍（≈10 帧）；句尾放宽到 2 拍 | 18% | 13%（另 14% 为高速转场） | 每 2 拍换一次排布，大字号 |
| **T3 慢速** | A / D / G / J | 2–8 拍，推拉代替硬切 | 无 | 极少，只有偶发单帧失真 | 明朝竖排、逐字打出，稳定 |
| F1 | 沉默 + 鼓点 | 黑屏，鼓点触发 2–3 帧闪现 | — | — | 无 |
| F2 | 警报 | 2 拍，中等节奏 | 少量 | 警报周期触发 | 无 |

T1 和 T2 的区别只差一档：T2 的单个画面能被看清，有"落地"的锚点镜头（同一句里反复回到同一张主图：A-B-A-C-A…）；T1 不保证看清。

### 0.2 镜头分两类

**意象镜头**（承载歌词，每句 2–5 个变体）
- `FULL` 满幅背景，缓推 / 漂移
- `CROP` 极端裁切：瞳孔、嘴、锁链一节、月亮的一角
- `CHAR` 角色在平涂底或背景上
- `SIL` 组件剪影压在纯色上（高反差）
- `SPLIT` 2–4 格分屏 / 横条切片，同时出现多张组件
- `WORD` 歌词关键字整屏（明朝），压在反色底上

**填充帧**（无意义，只负责过载）
- `TERM` 终端垃圾：hexdump、内存映射、kernel panic、进程表、校验失败、坐标流、`NO SIGNAL`、SMPTE 色条、进度条
- `FRAG` 已有组件的碎片：随机裁切 + 反色 / 单通道 / 阈值化 / 色调分离
- `ABS` 纯抽象：噪声场、平涂色块、扫描线场、条纹、棋盘、黑帧

### 0.25 高速动效（2026-10-09 校准：过载 10 分 → 8 分）

- 原闪插的约 35% 改为 3–4 帧高速转场：横 / 竖甩镜、推入（白色分割线）、穿越变焦、横条交错滑入、旋转突入，全部带方向性运动模糊。
- 其余意象镜头带入场动作：快速推近收回（punch）或冲击抖动（shake）。
- 每个镜头带持续快速漂移，静帧不死。
- 整槽填充只用有内容的（TERM / FRAG / 色条 / 色块马赛克，不偏色）；雪花、平涂、黑帧、偏色碎片只做 1–2 帧闪插。

### 0.3 闪烁

- 闪插默认用暗色、彩色块、局部反色、FRAG 碎片，**不做连续的全屏高亮频闪**。
- 全屏白闪 / 全屏反色只用在关键点：B 开头「電撃」、「舟は爆ぜた」、C/H 首拍冲击、I「熱異常」、I 结尾过曝。

### 0.4 字体

- 系统层（HUD、LOG、读数、TERM 填充帧、标注）：**Fusion Pixel 12px（日文）**，字号只用 12 的整数倍（24 / 36 / 48 / 72 …）保证像素锐利。小字用 Fusion Pixel 8px（16 / 24）。
- 歌词：保留明朝（Noto Serif JP）。
- 授权：Fusion Pixel / DotGothic16 为 OFL，PixelMplus 为 M+ 授权，文件在 `pv/public/fonts/`。

### 0.5 失真层（全局，常驻）

强度 `d = 底噪 + heat 增量 + 段落增量`：A 段很轻，I 段峰值，J 段回落到只剩底噪。任何时候都不盖过画面主体。

强度曲线（2026-10-09 第二次调整）：未升温时明显减弱——`d = 0.04 + 0.6·heat^1.3 + 段落加成·(0.5+heat)`，撕裂概率、色偏、重影、滚动带都随 d 缩放、不留固定下限；切点冲击在低温时打七折。

**模拟信号干扰**（2026-10-09 加强）
- 横向撕裂：以 10–400px 的宽带为主，偶有细条；宽带内轻微提亮并带一条亮边。切点、闪插处概率更高。
- 色偏：RGB 通道水平分离，底噪 2–8px，切点和撕裂时更大。
- 拖影：多径重影（右侧淡副本）+ 水平拖尾。
- 滚动干扰带：一条宽亮带从上往下滚过，经过处画面剪切错位，带一条亮线。
- 垂直同步跳帧：偶发 1–2 帧整幅上下跳动。

**传感器 / 辐射噪声**
- 白色亮点：每帧随机散布的 1–3px 白点，数量随 heat 增长。
- 坏点累积：固定位置的常亮坏点，**数量随全曲时间累积增加**（设备在辐射 / 高温下持续损坏），J 段也不消失。
- 亮线：偶发整列 1px 竖向亮线（CCD 溢出），以及整行掉线。
- 底噪颗粒 + 扫描线 + 暗角。
